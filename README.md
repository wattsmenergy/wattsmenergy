# WattsM Energy Solar Portal - Model-specific ALMM Status

The portal now shows status, validity dates, and source revision for each selected panel model. Exact RenewSys DESERV EXTREME R-600 through R-620 entries are marked LISTED based on MNRE ALMM List-I Revision 51 dated 16 September 2026, with displayed validity 7 February 2026 through 6 February 2030, subject to valid BIS registration. Other catalogue entries remain VERIFICATION REQUIRED unless an exact model match is established from the official list.

Never infer ALMM status from brand, wattage, or product family. Re-check the latest official List-I before purchase, quotation, subsidy filing, or commissioning.

Deploy by uploading `index.html` to any static host.
